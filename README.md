# Nivedhitha J. — Portfolio

A dark, futuristic AI/full-stack developer portfolio built with Next.js, TypeScript, Tailwind CSS v4, Framer Motion, and Lucide React.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Add your resume
Copy your latest PDF resume into `public/` and name it `Nivedhitha_J_Resume.pdf`. The hero section links to `/Nivedhitha_J_Resume.pdf`.

## Before publishing
- Confirm certification titles and dates.
- Add RicozSpark and MentorHub repository/demo links when available.
- Review every project description and update features as implementation changes.
- Add screenshots to project cards if desired.
- Run `npm run build` before deployment.

## Deploy
Push the repository to GitHub, import it into Vercel, and deploy using the default Next.js settings.
